# Sem conteúdo clínico no sistema

O sistema guarda só dados administrativos: cadastro, agenda, valores e notas. Prontuário, evolução, laudos e qualquer outro registro clínico ficam fora, mesmo que sistemas de referência como o PsicoManager ofereçam prontuário. Decidimos assim para manter o sistema simples e não assumir as exigências de sigilo e guarda do registro documental do CFP. O cadastro de pacientes continua sendo dado sensível de saúde pela LGPD e recebe os cuidados de acesso e segurança do sistema.
